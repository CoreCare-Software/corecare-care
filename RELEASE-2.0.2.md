# CoreCare Care 2.0.2

This release restores production account onboarding and strengthens support operations.

- Uses the Cloudflare Workers-supported PBKDF2 ceiling for new users, staff logins, family accounts and password changes.
- Opens owner support sessions on the customer organisation’s active branch.
- Records privacy-safe, request-correlated server errors in D1.
- Adds controlled branch archive and restore while retaining all historical records.
- Blocks branch archive until active users, clients, staff and future visits are reassigned, and protects the final active branch.
