# CoreCare Care 1.26.0 — Platform separation

This release separates the CoreCare software-owner workspace from the care-provider application.

## Changes

- Platform-owner users are redirected to `https://platform.corecare.co.uk`.
- Organisation users continue to use CoreCare Care normally.
- Authorised Support Mode remains available through CoreCare Platform.
- No care records, D1 tables, permissions, or organisation workflows are removed.

## Deployment

No database migration is required for this release.
