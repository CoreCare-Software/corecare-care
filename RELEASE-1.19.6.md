# CoreCare Enterprise v1.19.6

## Platform and organisation navigation separation

- Keeps organisation navigation hidden while a platform user is in the platform workspace.
- Prevents platform users opening tenant pages without an authorised support session.
- Keeps platform navigation visible until a deliberate organisation support session is started.
- Preserves the existing Support Mode banner and Leave Support Mode action for returning to platform operations.
- Removes accidental context switching caused by mixed navigation menus.

## Database migration

No database migration is required.
