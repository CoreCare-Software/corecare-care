# CoreCare Enterprise 1.13.2 — Recurring Visit Workflow Hotfix

- Fixes the recurrence editor crash caused by a missing explicit submit-button selector.
- Existing recurrence settings now populate when editing a recurring visit.
- Dragging or resizing a recurring visit asks whether to change this visit, future visits, or the whole series.
- Recurring series receive consistent colour accents on the rota.
- Recurrence saving has a visible saving state and safer error handling.
- The quick-add repeat wording now makes the recurring workflow clearer.

No database migration is required.
