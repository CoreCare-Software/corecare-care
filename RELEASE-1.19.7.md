# CoreCare Enterprise 1.19.7 — Carer Dashboard and Visit Workflow

## Included
- Dedicated mobile-friendly dashboard for carer and senior carer accounts.
- Shows only visits allocated to the logged-in staff record.
- Today metrics, next/active visit status, address, care-record actions and recent completed visits.
- Clear warning when a login is not linked to a staff record.
- Carer care-record endpoints now reject visits allocated to another worker.
- Clock-in/out opens the existing secure client-code workflow.

## Database migration
No migration required.
