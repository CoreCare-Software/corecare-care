# CoreCare Enterprise 1.13.1 — Rota-First Recurring Visits

This release makes recurrence available directly from the rota. Right-click a visit to make it recurring, change its pattern, pause it or stop it. The recurrence wizard supports weekly, fortnightly and four-weekly patterns, multiple weekdays, retaining the allocated carer, end dates and occurrence limits. Recurring visits display a visible recurrence badge and continue to use the existing template generation and travel-aware scheduling engine.

Database migration: `0030_rota_first_recurring_visits.sql`.
