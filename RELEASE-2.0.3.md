# CoreCare Care 2.0.3

This release makes organisation module visibility complete, reliable and immediately effective.

- Shows the full 15-area Care catalogue even when an organisation has no existing module rows.
- Lets authorised owners and managers turn optional areas on or off for the whole organisation.
- Applies changes immediately to the current navigation and to subsequent requests for every user.
- Enforces disabled modules in the Worker as well as hiding them in the interface.
- Keeps Dashboard, Clients, Staff, Care plans and Settings always available to prevent unsafe lockout of core care records.
- Seeds module settings for existing organisations and every new organisation created through either onboarding path.
- Records every module change in the existing audit history.
