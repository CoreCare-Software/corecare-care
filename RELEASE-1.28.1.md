# CoreCare Care 1.28.1 — Secure sign-in experience

Introduces a dedicated CoreCare Care login experience while retaining the existing D1 authentication and secure session flow.

- Makes the CoreCare Care product identity explicit on the sign-in page.
- Keeps the complete form visible at common laptop and mobile viewport sizes.
- Replaces fictional dashboard statistics with honest product-capability highlights.
- Adds clearer password recovery guidance and protected-access messaging.
- Prevents first-time visitors and invalid credentials from being labelled as expired sessions.
- Adds release consistency checking for both deployed CSS and JavaScript cache keys.

No database migration is required.
