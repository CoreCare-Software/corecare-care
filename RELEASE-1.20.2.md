# CoreCare Enterprise 1.20.2 — Carer Workspace Isolation

## Database migration
No database migration is required.

## Fixes
- Standard carers now receive only the My Visits dashboard.
- Rota, all-carer visit board, staff and client management navigation is removed from the carer workspace.
- Empty sidebar headings are hidden.
- Management rota and visit-board APIs now reject carer accounts server-side.
- The dashboard navigation is labelled My visits for carers and remains functional.
- Carer dashboard data remains filtered by the login-linked staff ID.
