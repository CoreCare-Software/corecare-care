# CoreCare Enterprise 1.16.3 — Visit Card Readability

- Client names are now the strongest visual element on allocated and unallocated visit cards.
- Visit names can wrap to two lines.
- Cards use a larger minimum width while retaining their scheduled timeline position.
- Hovering a card shows the full client, time range, visit type, allocation and scheduling flags.
- Existing visit badges, drag/drop, resize and double-click editing are retained.

Database migration required: No.
