# CoreCare Enterprise 1.2.1 — Platform Page Navigation

## Changes

- Platform navigation now opens distinct application views instead of scrolling down one long page.
- Command Centre, Revenue, Customer Success, Organisations, Global Search, Operations and Security & Audit each have their own workspace view.
- Browser back and forward navigation is supported with URL hashes.
- Page title and navigation state update for every platform view.
- Existing live data, actions and permissions remain unchanged.
- No database migration is required.
