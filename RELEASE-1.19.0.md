# CoreCare Enterprise 1.19.1 — Care Delivery Visit Workflow

Begins Phase 1 Care Delivery with a complete visit-record workflow layered onto the existing rota and electronic call monitoring system.

## Included
- Structured visit care notes and wellbeing observations
- Mood, nutrition, hydration, toileting, mobility and skin observations
- Visit task completion checklist
- Medication administration/support outcomes
- Manager follow-up task escalation
- Incident creation directly from a visit
- Completed visit care-record retrieval and editing
- Responsive care-delivery interface

Database migration required: `0033_care_delivery_visit_records.sql`.
