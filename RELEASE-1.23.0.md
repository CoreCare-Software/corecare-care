# CoreCare Enterprise v1.23.0 — Structured Care Plans

## Included
- Person-centred structured care-plan builder.
- Twelve optional care and support domains.
- Needs, outcomes, staff instructions, risks and preferences per domain.
- Consent, capacity and decision-maker recording.
- Version snapshots including structured domains.
- Editing returns a plan to approval pending.
- Manager approval activates the current version.
- Review dates and care-delivery alerts remain integrated.

Apply migration `0035_structured_care_plans.sql` before deployment.
