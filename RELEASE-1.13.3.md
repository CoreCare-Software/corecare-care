# CoreCare Enterprise 1.13.3 — Unified Visit Template Editor

- Recurrence and visit templates are now managed inside the normal double-click Visit Details editor.
- Right-click recurrence actions have been removed.
- Existing recurrence settings load into the editor.
- Pause, resume and stop controls are available in the template section.
- Stopping recurrence detaches the selected visit, immediately removing its recurrence badge while retaining it as a one-off visit.
- No database migration is required.
