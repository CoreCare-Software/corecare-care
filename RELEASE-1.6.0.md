# CoreCare Enterprise 1.6.0 — Custom Access Control

This release makes CoreCare adaptable to each provider through organisation-wide module controls, custom roles and individual user permission overrides.

## Included
- Organisation module visibility controls
- User-specific Allow, Deny or Inherit permission settings
- Expanded permission catalogue for scheduling, visits, live operations, medication, tasks, incidents and finance
- Effective permissions returned at sign-in
- Navigation automatically hidden when a user cannot access a module
- Direct user overrides take priority over role permissions
- Organisation isolation on every access-control record
- Audit events for module and user permission changes
