# CoreCare Enterprise 1.7.0 — Visual Scheduling Board

## Included

- Drag-and-drop day scheduling board with carers down the left and hourly timeline across the top.
- Unallocated visit tray.
- Drag to allocate, reassign or change visit time.
- Drag visits back to Unallocated.
- Resize visits in 15-minute increments.
- Board, week and list views.
- Live visit status visible on scheduled calls.
- Existing clash detection and tenant isolation retained.
- Existing rota records remain the same live visit records used by Electronic Call Monitoring.

## Database migration

Not required.
