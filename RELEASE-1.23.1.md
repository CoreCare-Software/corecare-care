# CoreCare Enterprise v1.23.1 — Branch Editing

## Changes

- Added an Edit branch action to Organisation settings > Locations > Branches.
- Branch name, code, address, phone, email and status can now be updated.
- Added active/inactive branch status management.
- Added validation and an audit entry for every branch update.
- Existing branch-linked users, clients, visits and records are preserved.

## Database

No database migration is required.
