# CoreCare v1.24.1 — Medication & Client Stability

## Fixes
- Medication client selector now uses CoreCare's normal client display names.
- Add Medication close, cancel and save controls are reliable.
- Medication validation and API errors display inside the dialog and the save button cannot be double-clicked.
- Added an offline UK medicine autocomplete catalogue with common names, forms, strengths and routes. Prescribed details remain editable.
- Client verification QR generation is now bundled locally and no longer depends on an external CDN.

## Database
No migration is required for this release.
